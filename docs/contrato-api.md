# Contrato da API

O contrato completo (recursos, filtros, formato dos registros, paginação, erros e cache) está na
seção "Contrato da API" do roteiro do projeto.

Com o ambiente no ar, a documentação gerada a partir do código fica em:

- Swagger UI: http://localhost:8000/api/v1/docs/
- ReDoc: http://localhost:8000/api/v1/redoc/
- Esquema OpenAPI 3: http://localhost:8000/api/v1/schema/

Mudanças incompatíveis no contrato dão origem a uma nova versão (`/api/v2/`), e a anterior
continua disponível.
